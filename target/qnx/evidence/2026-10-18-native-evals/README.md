# QNX native evaluation evidence

This directory contains raw QNX 8.0 Raspberry Pi 5 evaluation artifacts
captured over the verified direct Ethernet connection on 2026-10-18.
The evaluated repository baseline is commit
`7778ee028347acb8793b7fd81d3d92f63ff57d37`.

Results and limitations are summarized in `REPORT.md`. The `raw/`, `logs/`,
and `runner/` directories preserve per-call data, errors, and durable-runner
state.
